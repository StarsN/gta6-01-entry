**Palmera Heat** is a top-down open-world crime game set in Palmera, a fictional coastal city you are free to roam on foot or behind the wheel. Wander the streets, steal vehicles, and push through moving traffic and crowds of pedestrians as you work through a 6-mission story handed out by Rosa Delgado, Marcos Vale and Ines Park. Fights can be settled up close or at range, and trouble draws attention fast — a 0–5 star wanted level brings police chases that escalate the longer you stay in it. The game wraps that action in a HUD with a live minimap, a start screen, pause, and a localStorage save so a run can be picked back up later, and every sound effect you hear is synthesized live with WebAudio rather than played from audio files.

Controls: WASD/arrows to move and drive, E to enter/leave a car, Shift to sprint, mouse to aim, click/Space to fight and shoot, R to reload, P/Esc to pause, M to mute.

## Run it

```sh
node serve.ts
# serves the game at http://localhost:8080 for desktop Chrome
```
